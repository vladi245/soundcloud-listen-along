# Security Policy

## Supported versions

Use the latest extension release. Security fixes ship in new releases.

## Report a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, or pull request.

Use GitHub's [private vulnerability reporting](https://github.com/vladi245/soundcloud-listen-along/security/advisories/new). Include:

- affected commit or version;
- prerequisites and reproduction steps;
- expected and observed impact;
- a minimal proof of concept, if safe;
- any suggested mitigation.

If GitHub does not offer the private reporting form, contact me through [GitHub](https://github.com/vladi245) to arrange a private channel without publishing vulnerability details.

Reports about the public room server belong here. Reports about someone else's self-hosted server should go to that server's operator unless the issue originates in this project's code or protocol.

Please avoid accessing other people's data, disrupting services, or exceeding what is necessary to demonstrate the issue.
