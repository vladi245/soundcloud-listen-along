# Security Policy

## Supported versions

The project is in early development and has no supported release. Security fixes are applied to the current default branch when practical; no response or remediation timeline is guaranteed.

## Report a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, or pull request.

Use GitHub's [private vulnerability reporting](https://github.com/vladi245/soundcloud-listen-along/security/advisories/new). Include:

- affected commit or version;
- prerequisites and reproduction steps;
- expected and observed impact;
- a minimal proof of concept, if safe;
- any suggested mitigation.

If GitHub does not offer the private reporting form, contact the maintainer through the [GitHub profile](https://github.com/vladi245) to arrange a private channel without publishing vulnerability details.

Reports about a self-hosted backend should go to that backend's operator unless the issue originates in this project's extension or documented protocol.

The maintainers will acknowledge actionable reports when available, investigate, coordinate a fix and disclosure as appropriate, and credit reporters who request credit. Please avoid accessing other people's data, disrupting services, or exceeding what is necessary to demonstrate the issue.
